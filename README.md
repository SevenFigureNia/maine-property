# 🌱 Lawn Mowing Landing Page

A modern, landing page designed for a professional lawn mowing and landscaping business.

## 📌 About the Project

This project is a simple business landing page created to showcase lawn care services and make it easy for potential customers to learn about the business and get in touch.

The goal was to create a clean, approachable design that gives customers the information they need without overwhelming them.

## ✨ Features

- Professional lawn care-focused design
- Service information section
- Business call-to-action
- Contact/booking section
- Custom imagery
- Clean and user-friendly layout
- Mobile-friendly design

## 🛠️ Built With

- HTML5
- CSS3
